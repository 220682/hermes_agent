# Flujos de negocio

## Qué vive acá

Las reglas de negocio permanentes del sistema, una vez por tema dueño, en archivos `NN-<tema>.md`. Aquí se agrega el índice de flujos a medida que se crean.

## Qué no vive acá

Estado de planes, bitácoras de sesión o procedimientos de agentes (eso vive en `../00-estandar-agentes/` y `../02-trabajo-activo/`).

## Qué leer después

`../00-estandar-agentes/05-aprendizaje-continuo.md`, para saber cómo se integra una regla nueva en un flujo.
