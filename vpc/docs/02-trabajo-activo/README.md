# Trabajo activo

## Qué vive acá

Cada plan de trabajo real vive como el mismo nombre base (`YYYY-MM-DD-<tema>.md`) en tres subcarpetas vinculadas 1-a-1:

```text
01-planes/YYYY-MM-DD-<tema>.md    → intención aprobada: qué se hará y cómo se aceptará
02-progreso/YYYY-MM-DD-<tema>.md  → estado vivo: qué se ha hecho, qué falta, qué bloquea
03-evidencia/YYYY-MM-DD-<tema>.md → demostración: qué se verificó y con qué resultado
```

## Qué no vive acá

No se crea una carpeta por plan. Las reglas de negocio permanentes viven en `../04-flujos-de-negocio/`; el aprendizaje/mejoras viven en `../03-aprendizaje-continuo/`.

## Qué leer después

El README de cada subcarpeta (`01-planes/`, `02-progreso/`, `03-evidencia/`) explica su ciclo de vida específico.
