# Material de apoyo

## Qué vive acá

Material de referencia que se conserva pero no es fuente de verdad ni parte del flujo activo. Este README se actualiza cada vez que se agrega, mueve o retira material.

## Qué no vive acá

Fuentes de verdad, planes, aprendizajes, diseño, ni credenciales o datos reales sin autorización.
