# Skills

## Qué vive acá

Skills reutilizables del repositorio, cada uno en `<nombre>/SKILL.md`. Se crean cuando un procedimiento reusable ya se repitió, el Auditor propone `PROPONER SKILL` y el Gate 2 lo aprueba; los crea el Orquestador (ver `../../docs/00-estandar-agentes/04-flujo-sdd-y-planes.md`, paso 16c).

Cada skill se redacta de forma agnóstica, para poder copiarse a otros repositorios sin depender de nombres, rutas ni datos propios.

## Qué no vive acá

Mejoras de trabajo que aún no son un procedimiento repetido (eso vive en `docs/03-aprendizaje-continuo/historico.md`).
